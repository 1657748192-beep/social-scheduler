# Instagram 评论与基础帖子数据设计

## 目标

在 Social Scheduler 的已发布帖子管理中，为本软件发布的 Instagram 帖子提供评论查看、人工回复以及基础互动数据，同时维持现有账号连接和发布能力。

## 范围

- 只支持 Social Scheduler 已成功发布并保存了 Meta 帖子 ID 的 Instagram 帖子。
- 用户可在帖子管理中展开帖子，按需读取点赞数、评论数和评论列表。
- 用户主动填写回复并点击发送后，软件才向 Meta 发布该回复；不做自动回复。
- 评论和统计数据按需从 Meta 读取，不在本地数据库持久化评论正文或互动指标。
- 首版不读取用户在 Instagram 原生发布或由其他软件发布的帖子，不包含 Facebook、私信、实时通知、隐藏/删除评论、自动化回复、触达率或曝光量分析。

## 用户体验

- Instagram 已发布帖子增加“查看评论/数据”入口；展开时请求该帖互动数据和评论。
- 提供手动刷新。加载、无评论、接口失败、权限不足和授权过期时展示可理解的中英文状态。
- 每条评论提供回复输入框和明确的发送按钮；发送前可编辑内容，发送后更新列表并提示结果。
- 评论功能需 Instagram 账号拥有者完成新权限授权后才能使用。没有该权限时显示启用/重新授权入口，原有帖子发布仍可用。
- 评论读取遵循工作区成员访问控制；回复权限与工作区内容编辑/发布权限保持一致，viewer 角色不可发送回复。

## 权限与 Meta API

- 沿用当前 Instagram Login、已获批的 `instagram_business_basic` 和 `instagram_business_content_publish`。
- 增加 `instagram_business_manage_comments`，仅用于读取已连接专业账号自有帖子的评论并回复评论。
- 当用户启用评论时走显式授权升级；授权请求保留当前必要权限并补充评论权限。未启用功能的账号不要求立即重新授权。
- 点赞数和评论数作为首版基础数据。若 Meta 对特定指标另有权限、账号类型或数据窗口限制，以当时接口契约为准；首版不申请触达/曝光等额外 Insights 能力。
- 所有 Meta API 请求由后端使用已加密保存的账号凭证执行。缺少评论权限只将评论功能标为不可用，不得把账号整体标记为发布授权失效。
- Meta App Review 通过前，仅允许 Meta 应用角色/测试账号验证该功能；获批后再向普通用户开放。

## 后端设计

- 复用 `PublishJob.providerPostId` 作为 Instagram 媒体 ID；扩展已发布帖子响应，在工作区校验后向前端提供该 ID。
- 增加工作区作用域的 Instagram 互动接口：读取某条已发布帖子的指标和评论、对评论提交人工回复。
- 所有接口校验登录身份、工作区成员身份、帖子属于该工作区且平台为 Instagram；回复接口还校验成员可编辑内容。
- 对 Meta 返回的缺权限、凭证过期、评论已删除/不可回复、速率限制和临时网络错误做区分，并返回适合界面展示的错误，不写入凭证或评论正文日志。
- 评论与统计按需读取；评论列表需支持 Meta 分页，避免一次读取无限结果。
- 不新增数据库表或 migration。

## 安全与兼容

- 不把 Instagram access token 返回给浏览器。
- 回复正文仅用于当前请求，不写入数据库或常规日志。
- OAuth 增量授权失败或用户拒绝时，保留已有凭证和发布 scope，避免使原发布功能失效。
- 未获得 `instagram_business_manage_comments` 的账号仍能照常发布，并能继续使用原帖子管理功能。

## 验收标准

1. 工作区成员可以查看本软件发布的 Instagram 帖子的点赞数、评论数和评论；其他平台帖子不展示 Instagram 互动入口。
2. 用户点击发送后，回复在 Meta 成功时显示成功并更新列表；失败时保留输入并提供可理解的原因。
3. viewer 角色不能发送回复；跨工作区或伪造媒体 ID 的访问被拒绝。
4. 没有评论权限、token 过期或 Meta 暂时不可用时，现有 Instagram 发布与帖子管理不受影响。
5. OAuth 升级不会丢失已存在的 Instagram 发布 scope；用户取消授权不会覆盖现有有效凭证。
6. 前端中英文文案、加载/空/错误/权限状态均有测试覆盖；后端权限、所有权、分页、回复成功及错误分类均有测试覆盖。
7. Meta 审核材料能演示授权评论权限、打开软件发布的 Instagram 帖子、查看评论并由用户手动回复；帖子数据展示与申请说明一致。
