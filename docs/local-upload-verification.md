# 本地分块上传验证记录

## 验证范围

视频不少于 8MiB 时使用现有服务器的 1MiB 分块上传，小视频和图片保留普通上传，单文件上限仍为 250MiB。未创建云资源、存储桶或付费加速服务；平台授权、绑定和排程接口保持原有用途，Worker 不需要修改或重启。

本地验证使用独立 PostgreSQL 和 Redis、随机工作区及临时 uploads 目录。排程验证只创建未来任务，真实 BullMQ 队列使用随机测试前缀，没有启动发布 Worker，也没有向社交平台发布内容。

## 上传与恢复

`apps/api/tests/localUploadEndToEnd.integration.test.ts` 使用 9MiB 合成视频字节，通过真实 HTTP、磁盘、数据库和 Redis 验证以下流程。

- 客户端丢弃一个已确认块的响应，再中断下一块。重新初始化同一上传后，服务端返回四个已确认块，只补传剩余五块。
- 合并文件的字节数和 SHA256 与原数据一致，重复完成请求返回同一素材 ID，分块上传只生成一条 ready 素材。
- 素材可通过原有接口保存草稿、创建未来排程并在排程列表读取。已有测试账号绑定、授权 scopes 和原排程记录保持一致。

一次本地对照测试每发送 64KiB 等待 5 毫秒，结果如下。恢复耗时是该次本地测试的实际墙钟时间，不代表腾讯云线路带宽或用户真实视频上传耗时。

| 方式 | 中断时可复用的确认量 | 恢复需发送的视频量 | 中断请求中损失的视频量 | 本次恢复耗时 |
| --- | --- | --- | --- | --- |
| 分块上传 | 4MiB | 5MiB | 0.5MiB | 2078 毫秒 |
| 原整文件上传 | 0 | 9MiB | 4.5MiB | 2578 毫秒 |

该场景减少了 4MiB 的重新发送量。分块不会增加运营商带宽，也不压缩或降低原视频画质。

## 实施决定与误判成本

1. 共用测试环境保护函数，避免 CLI 与测试夹具规则漂移；误判成本：调整一处测试工具。
2. 提取静态上传包装器，以独立测试真实私有路径边界；误判成本：将小包装器合回 app。
3. 同一 Redis 增加有界连接，避免共享队列连接无限重试；误判成本：多一条既有服务连接，无新资源。
4. 合并接口增加可选 MIME 与安全扩展名映射，保留 WebM／MOV 类型；误判成本：调整一个参数与映射。
5. 使用私有尝试凭据和磁盘检查边界，证明文件归属及实际存在；误判成本：清理前保留少量元数据。
6. Facebook 旧测试使用数据库时钟加 1ms，避免 Windows／Docker 时钟差；误判成本：调整测试辅助函数，生产逻辑不变。
7. 增加本地在途操作登记及安全磁盘枚举，支持取消、关停和清理；误判成本：维护一个小模块及磁盘接口。
8. 提取 API 关停辅助函数，避免等待未完成请求导致死锁；误判成本：调整辅助函数，超时策略不变。
9. 共用 UploadHttpError 并重新导出，避免错误处理循环依赖；误判成本：移动一个类，响应格式不变。
10. 增加可恢复、在途字节和会话进度字段，用于准确展示及取消；误判成本：调整增量字段，素材回调不变。
11. 旧请求增加可选 AbortSignal 与缓存遗忘辅助，阻止切换账号／工作区后的旧回调；误判成本：调整可选参数，旧调用不变。
12. 保护语言偏好存储访问，避免存储不可写导致上传界面崩溃；误判成本：受限浏览器无法持久保存语言偏好。
13. 扩展独立 HTTP 夹具连接真实草稿／排程路由并先关闭子进程；误判成本：调整测试生命周期，生产目录不变。
14. 只在测试子进程给真实 BullMQ 增加随机前缀，避免污染共享队列；误判成本：替换测试包装器，生产 Worker 不变。
15. 整分支审查安排在部署前，优先满足安全门槛；误判成本：发布前额外等待一次审查，无重复审查。
16. 用既有 PostgreSQL 锁串行核算合并容量，保守计算在途输出；误判成本：可能临时返回 507，并非防止其他进程占盘的硬配额。
17. 云端状态、部署和回滚能力单独验收，不从本地测试推断；误判成本：额外运维核验时间。已完成上线核验，回滚仅准备未演练。
18. 不宣称真实线路提速；误判成本：后续需用户实际上传验证，无付费加速。
19. 不宣称断电级持久性；误判成本：宿主机突然断电可能需要重新上传。
20. COS 不启用也不验收；误判成本：未来迁移 COS 时另做集成验证。
21. 只延长测试看门狗，避免把前置数据库延迟误判为读取挂起；误判成本：坏测试最多等待 5 秒。
22. 使用已有 TAT 替代不稳定终端连接；误判成本：新增命令执行记录，不新增权限、资源或收费上传。
23. 按用户明确选择推送并部署，保留现有分支及含无关改动的工作树，不自动合并或建 PR；误判成本：未来需要整合时再由用户选择。
