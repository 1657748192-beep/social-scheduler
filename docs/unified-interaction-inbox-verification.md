## 实施裁决与边界

1. 用依赖注入工厂公开计划中的服务方法，避免全局用户状态；风险由真实HTTP装配测试覆盖。
2. Prisma从测试库生成的差异含历史索引/FK漂移，只保留新域语句；漏约束风险由跨区/源身份真实DB测试覆盖。
3. 增加第二份新表约束迁移绑定冗余platform/appNamespace，阻止伪装平台绕过Facebook正文禁止复制的CHECK；不修改已应用迁移。
4. 账号目录先需要分页，因此Task3提前引入Task6的通用签名游标，后续复用；错上下文游标拒绝。
5. 不伪造后台用户/会话做新域投影；新统一列表使用已授权的可见/手动刷新，原Facebook验签接收照旧。没有新建无人值守订阅或恢复退役Instagram泵。
6. 用本地审计引用原Facebook SendAttempt，补充显式人工send-check；跨标签页换请求编号不能绕过未知结果保护。核对动作不发送、不改写原平台结果。
